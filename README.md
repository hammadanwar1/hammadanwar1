### 🌟 Featured Projects

#### 🤖 Joni AI
*Private repository · Next.js 16 · React 19*

An AI-powered web platform with a chat-style interface, real-time updates, crypto wallet support, and built-in payments.

**Key features**
- 💬 **AI chat interface** with Markdown rendering and syntax-highlighted code blocks
- ⚡ **Real-time communication** using Socket.io
- 📄 **Document uploads**: reads PDF, Word (.docx), Excel, and ZIP files in the browser
- 🔐 **Multiple sign-in options**: Google, Apple, and email/wallet login
- 🦊 **Web3 wallet integration** with Wagmi, Viem, WalletConnect, and Magic
- 💳 **Payments** through Airwallex
- 📱 **QR code** generation and scanning
- 📊 **Interactive charts and dashboards** with Recharts
- 🎨 **Smooth animations** with Framer Motion and a responsive layout

#### 📈 Crypto Analytics Dashboard
*Private repository · Next.js 15 · React 19 · Redux*

A data-rich Web3 dashboard with live market charts, wallet connection, and AI-powered features.

**Key features**
- 🕯️ **Trading-style charts** with TradingView Lightweight Charts, plus Highcharts, ApexCharts, and Chart.js
- 🎛️ **Visual indicators** such as gauges, speedometers, and animated odometer counters
- 🦊 **Wallet connection** with Wagmi, Viem, Ethers.js, and WalletConnect
- 🤖 **AI features** powered by the OpenAI API
- ⚡ **Live data** through Socket.io and React Query
- 🧊 **3D scenes and animations** with Spline, Lottie, GSAP, and Framer Motion
- 🗂️ **State management** with Redux, and a UI built with Material UI and Bootstrap

#### 💰 PROFT Landing Page
*Private repository · Vite 6 · React 18 · SCSS · GSAP*

A 13-section marketing website built pixel-for-pixel from a Figma design.

**Key features**
- 🎯 **Figma to code**: every section matched to its Figma frame, with design tokens shared across all styles
- 🌊 **Custom parallax and scroll-reveal system** built on GSAP ScrollTrigger, controlled with simple data attributes
- ♿ **Accessible motion**: all animation turns off for users who prefer reduced motion
- 🧮 **Interactive pricing estimator** with working range sliders
- 🎬 **Performance-minded media**: background video loads lazily so it doesn't slow the first paint
- 🧩 **Reusable components** such as a multi-size button and brand mark
